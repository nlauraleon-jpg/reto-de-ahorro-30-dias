# Reto de Ahorro · 30 Días

Una aplicación web sencilla para organizar un reto de ahorro de 30 días. Permite elegir una meta, seleccionar un método de ahorro y marcar los días completados. El progreso se guarda localmente en el navegador.

## Uso

Abre [`index.html`](./index.html) en un navegador moderno. No se requiere instalación ni servidor.

## Publicación

El sitio está preparado para publicarse con GitHub Pages desde la rama `main`, usando la carpeta raíz del repositorio.

## Privacidad

La meta y el progreso se almacenan en el almacenamiento local del navegador. No se envían a un servidor.
